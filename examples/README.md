# Sample Stack

`supplier-lead-times.stack/` contains a small, fictional supplier lead-times dataset with two Markdown Entries and a synthetic binary asset. It is retained as a reproducible fixture for Carbon's browser acceptance tests and as an optional import example.

To inspect it, open Carbon and choose **Open / Import**, then import the `supplier-lead-times.stack` folder. No external data or account is required.

The public distribution intentionally omits generated demonstration archives and long collections of Cast/Return examples. You can export a fresh archive directly from Carbon.
